★ The single most important cue

RV → PA: diastolic step-UP

The systolic peak stays about the same — but the diastolic floor lifts off zero. Same height, raised floor = you've entered the PA.

BALLOON RULE
Advance with the balloon ● UP (inflated, so it floats forward safely)  ·  Withdraw with the balloon ○ DOWN (deflated).
